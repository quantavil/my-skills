## Agent Usage Instructions

When addressing a design, redesign, or art-direction task:
1. Consult the **Routing Table** below to identify the guide covering the task.
2. ALWAYS load `references/taste-core-guide.md` first for pages, redesigns, and audits — it holds the binding rules (bans, hard caps, pre-flight).
3. Load the corresponding style/direction reference alongside it when the brief names an aesthetic or a medium.
4. Follow the checklists and pre-flight protocol; a single unticked box means fix before delivering.

All reference links are relative to this file. Never substitute guessed absolute paths.
